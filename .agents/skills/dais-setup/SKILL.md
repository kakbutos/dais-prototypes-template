# Подготовка Dais

Работай из корня проекта с package.json `dais-prototypes-template`. Сначала проверь Node; нужен 22.14+ из ветки 22 или 24+. Если Node/npm отсутствуют, направь к официальному установщику в README; не ставь произвольные системные пакеты.

1. Выполни `npm run setup`. Скрипт запускает npm ci, создаёт локальные конфиги MCP, синхронизирует skills и проверяет MCP реальными вызовами. Исходники трёх библиотек скачивать не требуется.
2. При проблемах используй `npm run doctor` и `npm run mcp:check`. Не обходи peer-конфликты через force/legacy-peer-deps и не заменяй зафиксированные пакеты на latest: сообщи точную ошибку.
3. Уточни используемый клиент, если это не видно из окружения. Перезапусти/попроси перезапустить агент после настройки MCP и пройти его штатную процедуру доверия проекту. Наличие конфига не доказывает, что клиент подключился: проверь доступный `dais-ui` вызов `get_component` для `TableCanvas`.
4. Запусти `npm run dev`, проверь страницу, дай фактический локальный адрес. Не публикуй проект в процессе одной только установки.

Команда установки повторяема и не удаляет `src/prototypes`. Конфиги содержат локальные абсолютные пути и исключены из git. Другие MCP-серверы и настройки сохраняются. GitHub-настройка описана в отдельном навыке dais-publish и нужна только при запросе публикации.
