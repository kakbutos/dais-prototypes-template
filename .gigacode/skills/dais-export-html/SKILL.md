# Автономный HTML

Прочитай `docs/HTML_EXPORT.md`. Если формат результата ещё не выбран, следуй вопросу из `AGENTS.md`; явный запрос HTML уже задаёт выбор. Экспорт включает всю галерею и исходные демоданные; изменения текущей браузерной сессии в файл не попадают.

1. Выполни `npm run export:html`: проверка TypeScript, сборка и проверка единственного выходного файла `dist-html/index.html`. При дополнительных ресурсах встрой их в сборку; не выдавай папку/ZIP вместо обещанного HTML.
2. Браузерные автотесты не требуются и не входят в шаблон. По правилам `AGENTS.md` проверь сам файл через `file://`, если изменён механизм экспорта, появились новые ресурсы/внешние зависимости, сообщена проблема открытия файла или пользователь просит проверку. Если экран уже проверен локально и упаковка не менялась, не дублируй весь просмотр при каждом экспорте. Для проверки автономности отключи сеть. Не заменяй проверку файла запуском dev-сервера и не устанавливай тестовый фреймворк ради обычного экспорта.
3. Передай путь к HTML, размер и фактический результат проверки. Если выполнена только сборка, кратко сообщи, что интерактивность автоматически не проверялась. Получатель скачивает и открывает файл в браузере; локальная ссылка `file://` не заменяет передачу файла. Экспорт не требует commit/push.

SB Sans Text / SB Sans Display берутся из `src/assets/fonts/` и встраиваются вместе с кодом. Получателю не нужны npm, Node.js, MCP или CDN. После изменения исходников повтори экспорт.
