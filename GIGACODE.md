# Dais prototypes

Прочитай `AGENTS.md`. Для GigaCode CLI навыки находятся в `.gigacode/skills`.
Подготовка: прочитай `.agents/skills/dais-setup/SKILL.md` и выполни `npm run setup`.
CLI получает MCP из `.gigacode/settings.json`; VS Code — из `.gigacode_vsc/gigacode.jsonc`.
Для клиента, который не подхватил навыки автоматически, можно попросить прочитать SKILL.md напрямую.
Поддержка изображения и выполнение команд зависят от выбранной модели, режима и политик организации. Не утверждай, что видел PNG, если клиент его не передал.
