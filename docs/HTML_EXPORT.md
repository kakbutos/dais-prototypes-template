# Один HTML-файл для коллег

GitHub, GitHub CLI, CDN и сервер для передачи готового прототипа не нужны.
Агент собирает настоящее React-приложение с Dais UI / TableCanvas в `dist-html/index.html`.
Все варианты галереи и их исходные демоданные входят в этот файл.

## Для дизайнера

После обычной локальной подготовки проекта попросите агента:

> Собери мои прототипы в один автономный HTML для передачи коллегам. Используй навык dais-export-html.

Или запустите в папке проекта:

```sh
npm run export:html
```

Передайте **только `dist-html/index.html`**, при желании переименовав, например, в `collection-demo.html`.
Получатель скачивает файл и открывает его в Chrome или Edge двойным щелчком либо через «Открыть файл».
Ему не нужны Node.js, npm, Git, MCP и доступ к интернету. Встроенный просмотрщик почты/мессенджера может не выполнять JavaScript — нужен обычный браузер.
Локальный путь `file://...` не является общей ссылкой: передавайте сам файл.

Для нового состояния измените исходники с агентом и выполните экспорт заново.
Редактирование получателем работает в памяти и сбрасывается при перезагрузке/выходе из варианта; сам HTML не перезаписывается.

## Для агента и разработчика

- `npm run export:html`: TypeScript → Vite в режиме offline → проверка, что в `dist-html` только один HTML.
- Браузерных автотестов нет. Обычный экспорт не запускает браузер и не устанавливает его.
- Если меняется упаковка/ресурсы, возникла ошибка открытия или нужна проверка автономности, откройте итоговый файл через `file://` с отключённой сетью. Для уже проверенного экрана без изменений упаковки полный повтор сценариев при каждом экспорте не нужен. Агент сообщает, выполнена только сборка или также проверены действия.
- Экспорт использует `vite-plugin-singlefile` с закреплённой версией; зависимости приложения остаются прежними. Обычная `npm run build` продолжает собирать сайт в `dist`.
- SB Sans Text и SB Sans Display версии 0.2.0 хранятся в `src/assets/fonts/` и встраиваются в HTML как WOFF2/data URL. Включены все 16 начертаний из исходных CSS: Text — 100/300/400/500/600/700 и курсив 300/400/600/700; Display — 100/300/400/500/600/700. Исходные адреса CDN и SHA-256 записаны в `SOURCES.json`. Сборка и просмотр не требуют CDN. Обычный сайт использует эти же локальные шрифты.
- Импортируйте изображения из исходников, чтобы Vite мог их встроить. Ресурсы `public/`, внешние картинки, API, iframe, worker и динамическая загрузка требуют отдельной проверки/адаптации. Однофайловая сборка сама по себе не делает произвольный экран автономным.
- Галерея использует hash-маршруты, совместимые с `file://`. В файловом режиме кнопка копирования ссылки скрыта.
- Стартовая установка зависимостей по-прежнему требует доступного npm registry и локальной копии шаблона. GitHub не требуется для самой сборки. После установки сборка не обращается к сети.

При разработке механизма экспорта 11 ноября 2026 проверено на macOS / Chromium: около 4,2 МБ для текущей коллекции, шесть браузерных сценариев без сети. Этот набор не входит в текущий шаблон; результат проверки не распространяется автоматически на новые макеты. Проверены загрузка всех 16 начертаний и фактическое использование SB Sans вместо fallback в заголовке и тексте. Windows / Edge отдельно не проверены. Возможность открытия локального HTML зависит от настроек браузера.
