# Проверка шаблона

## Текущие проверки

В шаблоне остаются `npm run typecheck`, `npm run build`, `npm run export:html`, `npm run doctor`, `npm run mcp:check` и `npm test` (три теста служебных скриптов). Браузерный тестовый фреймворк, его сценарии и команды удалены. Actions выполняет проверку кода и сборку без установки браузера. Агент проверяет UI доступными браузерными средствами соразмерно изменению, согласно AGENTS.md.

Ниже зафиксированы результаты проверки механизма экспорта до удаления браузерного набора. Они не означают, что каждый новый макет автоматически проверен.

## Автономный HTML — 11 ноября 2026

В отдельной копии проекта добавлен и проверен `npm run export:html`: один `dist-html/index.html` около 4,2 МБ, без соседних ресурсов. Все шесть браузерных сценариев пройдены через `file://` в Chromium с отключённой сетью; внешних запросов и ошибок браузера не было. Проверены реальные создание/редактирование/отмена/сброс, выбор строки, поиск, включение группировки и узкий экран. Встроены все 16 WOFF2-начертаний SB Sans Text / SB Sans Display 0.2.0. Проверены их загрузка без сети и фактически отрисованные шрифты заголовка/текста через Chromium DevTools Protocol (isCustomFont), а не только CSS font-family. Сборка и браузерные сценарии обычного сайта также проверены. Это не проверка Windows / Edge или всех настроек открытия HTML-вложений.

Дата: 10 ноября 2026. Локальное окружение: macOS, Node.js 22.14.0, npm 10.9.2, Chromium.

## Что проверено локально

- Установка в отдельную папку вне Dais UI, без node_modules, локальных конфигов MCP и ссылок на исходные репозитории; первый запуск с отдельным пустым npm cache.
- `npm run setup`: установка из lockfile без force/legacy-peer-deps, создание проектных конфигов MCP, проверка локального расположения зависимостей.
- Реальное подключение к установленному MCP через stdio из другой рабочей папки: доступны 11 инструментов; успешно вызваны get_installation_guide, get_component для TableCanvas и list_features. Индекс содержит Editing и Searching.
- Создание второго варианта «План команды», повторная подготовка окружения: новый вариант сохранён, исходный вариант остался без изменений.
- TypeScript и production-сборка Vite.
- Три автоматических теста служебных скриптов: сохранение других настроек/MCP и макетов, отказ от частичной перезаписи при ошибке конфигурации, защита от перезаписи варианта и выхода за его папку.
- Пять сценариев Chromium: галерея и прямая ссылка, фильтрация/создание/сброс после перезагрузки, поиск и включение группировки, выбор строки и реальное редактирование канвасной ячейки с сохранением/отменой, галерея на узком экране, сброс при повторном открытии варианта и отсутствие записи изменений в localStorage/sessionStorage.
- Скриншоты галереи и реестра просмотрены; они включены в README. Это стартовая композиция, а не заявление о полном совпадении с исходным PNG.

## Границы проверки

Конфиги для Codex, Claude Code, GigaCode CLI и GigaCode VS Code подготовлены по документации. Проверен сервер MCP и формат генерируемых файлов. Полный сценарий «открыть конкретный клиент → разрешить MCP → прикрепить PNG → получить новый макет» отдельно во всех этих клиентах не выполнялся. Для GigaCode VS Code автоматическое обнаружение навыков не подтверждено: предусмотрено прямое чтение SKILL.md.

Windows, Linux desktop и браузеры Safari/Firefox локально не проверялись. GitHub Actions выполняет проверку кода и сборку на Ubuntu; статус конкретной версии смотрите во вкладке Actions.

Сценарии не покрывают все возможности Dais TableCanvas. После изменения состава колонок или поведения варианта проверяйте его отдельно. Сборка предупреждает о размере общего UI bundle; для стартового прототипа это не препятствует работе.

Шаблон закрепляет проверенные версии, а не обновляет библиотеки при каждом запуске. Обновление описано в MAINTAINING.md. Изменения демо живут в памяти открытого варианта и сбрасываются при его закрытии/перезагрузке; совместного редактирования и backend нет.

Инструкция GETTING_STARTED.md сверена с официальными источниками. Системные установщики и вход в аккаунты на чистых macOS/Windows отдельно не проходились.
